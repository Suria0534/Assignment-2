## 📌 Overview

**Foodies** is a modern, fully responsive e-commerce website showcasing organic vegetables and healthy food products. The site features a professional design with multiple sections dedicated to product discovery, benefits, and customer engagement.

## ✨ Features

- 📱 **100% Responsive Design** - Mobile, Tablet, and Desktop optimized
- 🎨 **Modern UI/UX** - Clean, professional interface with green theme
- 🛒 **Product Showcase** - Featured products with ratings and pricing
- 💚 **Health-Focused Content** - Benefits and statistics about healthy eating
- 🔗 **Smooth Navigation** - Easy-to-use navigation menu
- 📱 **Social Media Integration** - Facebook, Instagram, Twitter links
- ⚡ **Fast Loading** - Lightweight and optimized code

## 📁 Project Structure

```
├── index.html           # Main homepage
```

## 🚀 How to Use

1. **Clone the repository:**
   ```bash
   git clone https://github.com/suriasultana57/foodies-website.git
   cd foodies-website
   ```

2. **Open in browser:**
   - Simply open `index.html` in your web browser
   - No server or installation required!

## 🎯 Sections

1. **Home** - Hero section with call-to-action
2. **Benefits** - Health benefits with checklist and statistics
3. **Features** - 4 food categories with descriptions
4. **Products** - Most popular products with ratings and prices
5. **Footer** - Company info, links, and contact details
